# PortLev Academy: Live Audit, September 2026

**Property:** learn.portlev.com (repo `learn-portlev`, Next.js 16, Vercel project `learn-portlev`)
**Audited:** 2026-09-02 against deployment `dpl_3WD8q86mw7Q6uW2pYhhx2oJfZ3yB` (commit `70bd5a2`, main)
**Method:** live fetches of `/program`, `/caio-course` and the 404 page, plus the deployed source at that commit for `/`, `/learn/*` and `/about`. The live `/`, `/robots.txt`, `/sitemap.xml` and `/llms.txt` fetches were rate-limited by the fetch proxy (HTTP 429), so those findings come from the deployed source, which is byte-identical to what Vercel built.

---

## 1. The headline finding

**The flagship program URL was a 404.** `https://learn.portlev.com/program`, the address the Chief AI Officer program is sold under from portlev.com and The Leverage Brief, returned:

```
<title>404: This page could not be found.</title>
<meta name="robots" content="noindex"/>
```

The program page actually lived at `/caio-course`. Any warm traffic sent to `/program` landed on the unstyled default Next.js error page (system font, `height:100vh`, no navigation into the funnel), with a `noindex`. This is the single largest conversion leak on the property and it is fixed in this rebuild (`/program` is now the canonical landing; `/caio-course`, `/course` and `/caio` 308 to it).

## 5. Mobile and performance smells

- **4.4 MB headshot** on `/about` via raw `<img>` (fixed, see above; the same file is now used through `next/image` in the new instructor block).
- **Fonts:** Geist + Geist Mono loaded for a site that never shows code to readers. Replaced with the house pair (Manrope display, Inter body) via `next/font`, self-hosted, `display: swap`. Net weight is similar; the brand is now correct.
- **Inline hex styles everywhere** (`style={{ color: '#0f172a' }}`) instead of tokens. Not a perf issue, a maintenance one. New surfaces use Tailwind tokens from `globals.css`; legacy pages keep their inline colors, which sit within a few RGB points of the house tokens, so the site reads as one system.
- **No sticky CTA on mobile** on the program page. Added (`components/StickyCTA.jsx`), appears after the hero, respects `safe-area-inset-bottom`.
- **No reveal/hover motion** on any surface. Added a single `IntersectionObserver` (`components/Reveal.jsx`) driving `[data-reveal]`, disabled under `prefers-reduced-motion`, with a no-JS fallback.
- **Layout shift:** hero had no fixed-size imagery, so CLS was already low. The new instructor image declares width/height and `sizes`.
- **Third-party scripts:** only `@vercel/analytics`. Good. Nothing added.

## 8. Addendum 2026-09-03: the duplicate host `claude-code-mastery-self.vercel.app`

Fetched live on 2026-09-03. `https://claude-code-mastery-self.vercel.app/` is **not** a mirror of this site. It is the legacy Astro/Starlight build (`<meta name="generator" content="Astro v6.3.2">`, Starlight v0.39.2, site name `PortLev Learn`, repo `YGK13/claude-code-mastery`) with different content: `<title>Build with AI | PortLev Learn</title>`, a six-module Claude Code curriculum (`/curriculum/01-getting-started/overview/` ...), a "Founding Cohort · 4 / 8 spots left" banner, "$2,500 (next cohort $4,500)", a Calendly vetting-call CTA and a `/sitemap-index.xml`.

What makes it a problem is one line in its `<head>`:

```
<link rel="canonical" href="https://learn.portlev.com/"/>
<meta property="og:url" content="https://learn.portlev.com/"/>
```

A cross-domain canonical is a hint to consolidate signals onto learn.portlev.com, but Google only honours it when the pages are near-duplicates. Here the content, the offer (8 seats at $2,500 rising to $4,500 vs. 15 seats at $2,500) and the instructor bio (33,000+ LinkedIn followers, Thinkers360, Forbes: none of which this site claims) all differ, so the hint is likely ignored and the `.vercel.app` host gets indexed on its own, competing for `PortLev Learn` / `Yuri Kruman AI curriculum` queries with stale pricing. Meanwhile learn.portlev.com (as deployed at `70bd5a2`) served **no** canonical of its own, so nothing on this side asserted which host is primary.

This rebuild asserts the primary on this side: every route now emits an absolute `<link rel="canonical">` on `https://learn.portlev.com` via `metadataBase`, plus Organization / WebSite / Person JSON-LD with stable `@id`s. What it cannot do from this repo (human to-do, listed in `docs/GTM-2026-09.md` section 12): in the `claude-code-mastery` Vercel project either (a) add a project-level 308 redirect from the `.vercel.app` host to `https://learn.portlev.com/`, or (b) if that curriculum is meant to live on, give it its own domain, its own self-referencing canonicals and pricing that matches the live cohort page, and drop the learn.portlev.com canonical. Option (a) is the 10-minute fix; the stale "4 / 8 spots" and "$4,500" copy argues for it.
